# 로컬 확장: 발표 덱·개조식 보고서 규범 (upstream 아님)

> 이 파일은 upstream(NomaDamas/k-skill)에 없는 **로컬 추가분**이다. 2026-07-31 인터넷 조사(한국 기업 문서 규범 + 영어권 AI-tell 카탈로그 + 커뮤니티 노하우)를 이 스킬의 어휘로 정리한 것. 대상 장르가 **발표 슬라이드(pptx)·개조식 보고서**일 때 본 파일이 SKILL.md의 장르 판단을 오버라이드한다.

## 1. 장르 오버라이드 (슬라이드에서 심각도가 바뀌는 패턴)

한국 실무 보고서·덱에서는 다음이 **정상 관례**다. 문서용 규칙을 기계 적용하면 과잉 교정이다.

| 패턴 | 문서 기준 | 슬라이드 기준 | 근거 |
|---|---|---|---|
| J-3 불릿 리스트 | S2 | **정상(제외)** | 개조식이 보고서 표준 형식 |
| J-1 굵은 머리말 불릿 | S2 | **S3** (전 항목 기계 반복일 때만) | 키워드 강조는 덱 관례 |
| C-9 숫자 인덱싱 (1)(2)(3) | S2 | **정상(제외)** | 행안부 항목 위계 체계 |
| 화살표(→) | S3 | **정상(제외)** | 흐름·추이·인과 요약의 실무 표준("선정 → 구성 → 구축") |
| 짧은 구·체언 종결 | E 계열 의심 | **정상(제외)** | 개조식 그 자체 |
| J-2 줄표(—·–) | S1 | **S1 강화** | 한국 실무 기호 목록(→·⇒·※·~·:)에 줄표가 아예 없음. 존재 자체가 외부 문법 |
| 가운뎃점(·) | S2 | **용도 한정 S1**: 밀접한 단어의 병렬 열거("조사·연구")만 허용. 구·절 연결, 수사적 끊기("빠르고·정확하고")는 제거 | 국립국어원 용법 + 실무 관행 |

## 2. 기호 치환표 (줄표를 걷어낼 때)

| 원래 용도 | 치환 |
|---|---|
| 부연·보충 ("X — 설명 — Y") | 괄호( ) 또는 문장 분리 |
| 소결론·시사점 도출 | ⇒ 또는 별도 행 |
| 참고·출처·단서 | ※ 또는 각주(*) |
| 기간·범위 | 물결표(~) |
| 용어 강조 | 작은따옴표(' ') |

## 3. 개조식 변환 규칙 (조사로 확인된 관행 요체)

1. **명사형 종결**: 모든 본문 항목은 ~함/~임/~됨/~기 또는 명사로 끝냄. "~합니다/~다/~죠" 서술 종결 제거.
2. **종결 통일**: 같은 층위 항목끼리 종결 품사(명사 종결 vs ~함 종결)·조사 유무·길이를 맞춰 리듬 형성. 문서 전체에서 마침표 정책(찍기/빼기)도 하나로.
3. **조사 생략은 의미 보존 한도까지만**: 주어와 원인-결과가 사라지면 안 됨(압축 과잉으로 명사 5~6개 연쇄되면 오히려 위반).
4. **한 항목 한 사실, 2~3줄 이내.**
5. **정성 표현 → 정량 팩트**: "가독성 향상"이 아니라 "조회 단계 3→1 축소". D-4(hype) 처방과 동일 원리.
6. **시제 워딩**: 완료 실적은 "~완료/기 구축", 계획은 "~예정/추진 중" (개조식의 시제 모호성 보완).
7. **헤더 이원화**: 슬라이드 제목=명사구(마침표 없음), 그 아래 거버닝 메시지 1줄=개조식 완결 주장(주어·결과 포함, 2줄 이내). 구어 의문 헤더("~가 뭔데?")는 발표 화법으로 돌리고 지면에서는 명사구로.
8. **가로 흐름 테스트**: 수정 후 거버닝 메시지만 이어 읽어 스토리가 성립하는지 검증.

## 4. 커뮤니티 합의 원칙 중 덱 작업 추가분

- **빼기+넣기**: 슬로건·의의 부여(D-4·D-8)를 지운 자리는 원문에 이미 있는 실측 수치·실물 사례로 채움. 빼기만 하면 "매끄러운데 힘이 없는" 글이 됨.
- **밀도 감축이 목표**: 단독 출현은 tell이 아님(SKILL.md 무더기 원칙과 동일). 정량 측정(수정 전후 카운트)으로 수렴 확인.
- **내부 은어 점검**: 청중이 공유하지 않는 코드워드(팀 내부 용어)는 일반 용어로 치환. AI-tell은 아니지만 "성의 없음"으로 지각되는 같은 부류.
